KYC Conversation Flow

START/start → greet + explain steps
CONSENTexplicit agree · logged to audit · decline → END
COLLECT_ID_FRONTphoto of ID (front) · back optional/configurable
LIVENESS_CHALLENGErandom: blink / turn head → short video
COLLECT_SELFIEsharpest frontal frame from the video
PROCESSINGasync: OCR + liveness + face match → Decision
✅ PASSverified
⏳ PENDINGmanual review queue
❌ FAILretry (capped 3) → else pending

Decision Logic

OrderConditionOutcome
1not liveness_passedFAIL — spoof suspected
2ocr_quality < Q_MINFAIL — unreadable (retry-eligible)
3face_sim ≥ PASS_HI and ocr_quality ≥ Q_OKPASS
4face_sim < FAIL_LOFAIL
5otherwise — face_sim ∈ [FAIL_LO, PASS_HI)PENDING_REVIEW
All thresholds are env-tunable in config.py. Every run writes an append-only audit record (scores, thresholds, decision). Identity-proofing MVP — not a compliance-certified product.
